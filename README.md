# dotfiles
arch + mango

# usage
Either copy/paste the code or create symbolic links like

`ln -s /path/to/original_file_or_directory /path/to/new_symlink`

I got code snippets from various places on the internet. If you see
that I mis-creditted you, let me know and I'll provide the reference
or delete.

List of config folders 
 * mango: ~/.config/mango
